# AuditChain Documentation

This directory contains supporting documentation for the AuditChain project.

## Documentation

The project documentation covers:

- Project overview
- Problem statement
- Objectives
- System architecture
- Process flow
- AI-assisted transaction extraction
- Risk analysis
- Potential duplicate detection
- Google Sheets transaction ledger
- AuditChain frontend
- Smart contract implementation
- Polygon Amoy blockchain testing
- Testing and results
- Limitations
- Future scope

## Project Status

AuditChain is an academic and technical proof-of-concept demonstrating how AI, automation, structured transaction records, and blockchain verification can support a financial auditing workflow.

The blockchain implementation uses the Polygon Amoy Testnet.
