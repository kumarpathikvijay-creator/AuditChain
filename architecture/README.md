# AuditChain System Architecture

This directory contains the system architecture and process-flow diagrams for the AuditChain prototype.

## Main Workflow

Transaction Document
↓
Tally / Webhook
↓
Make.com Automation
↓
AI Document Extraction
↓
AI Risk Analysis
↓
Potential Duplicate Detection
↓
Google Sheets Transaction Ledger
↓
AuditChain Control Room
↓
Audit Record
↓
AuditChain Smart Contract
↓
Polygon Amoy Testnet
↓
Blockchain Verification

## Architecture Components

- Input and transaction documents
- Workflow automation
- Google Gemini AI processing
- Risk assessment
- Duplicate transaction analysis
- Structured transaction storage
- AuditChain frontend
- Smart contract
- Polygon Amoy Testnet
- Blockchain explorer verification

> Note: AuditChain is an academic proof-of-concept. The blockchain implementation uses the Polygon Amoy Testnet and the system is not presented as a production financial auditing platform.
